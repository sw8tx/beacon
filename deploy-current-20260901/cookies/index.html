Cookie Policy

Last updated: August 25, 2026

1. What cookies do

Cookies are small text files or similar browser technologies that allow a website to remember information between requests. Local storage and session storage provide similar browser-based functionality. Together, these tools can keep a login working, remember a preference, protect a form, or show whether a temporary interface action has already happened.

This policy explains the categories Beacon may use and the choices available to you. It should be read together with the Privacy Policy, which explains the wider handling of information.

2. Essential technologies

Essential storage is used for functions that a visitor asks for or that are necessary to provide a requested service. Examples may include authentication state, security checks, language preferences, accessibility preferences, and temporary navigation state.

Blocking essential storage can cause login, dashboard, preference, or security features to stop working. These technologies are not intended to create an advertising profile about you.

3. Functional and promotional state

Beacon may store small interface states so that the website behaves consistently. For example, a browser may remember that an Easter promotional badge was already claimed so the same visitor sees a clear “Already claimed” state instead of being encouraged to repeat the action.

This type of state is normally stored locally in the browser. Clearing site data, using a different browser, or using a private window may remove it. A local browser flag is not a substitute for a server-side record where a promotion requires authoritative eligibility tracking.

4. Measurement and third parties

Where enabled and legally permitted, Beacon may use limited technical measurement to understand page performance, errors, and feature reliability. Third-party services may set their own technologies when you follow an external link, authenticate with Discord, or load content they provide.

Those third parties have their own policies and controls. Beacon does not control storage placed by Discord or another external website after you leave Beacon.

5. Your controls

You can view, delete, block, or restrict cookies and local storage through your browser settings. Many browsers allow you to control storage by site and to receive warnings when a website tries to set data. You can also use private browsing, although some Beacon features may not work normally there.

If a consent choice is presented, you can change it through the available controls or by clearing the relevant site data. Essential technologies may still be required for a feature you explicitly request.

6. Updates and questions

We may update this policy when the website, providers, or legal requirements change. The date at the top shows when the current version was published. If a change is significant, we may provide additional notice through the website.

For questions about browser storage or a privacy request, contact Beacon through the support option on the website. Please do not send passwords, access tokens, or payment details in an ordinary support message.
