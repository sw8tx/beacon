Welcome

/welcome-remove

Remove the active welcome panel cleanly when you no longer want Beacon to post join messages.

Usage

/welcome-remove

What it does

Beacon removes the configured welcome setup for the server and stops future join messages. Existing Discord messages are left untouched.

Set it up again

Run /welcome-configure and /welcome-create whenever you want to bring the panel back.
