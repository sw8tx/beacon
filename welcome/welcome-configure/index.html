Welcome

/welcome-configure

Build the welcome panel once, then let Beacon post the same polished message whenever someone joins.

Usage

/welcome-configure channel:#welcome

What you can change

Choose the channel, title, message, button labels, button links and thumbnail. Upload PNG, JPG, GIF or WEBP media directly in the Discord menu.

Available variables

{user} mentions the new member, {server} inserts the server name and {membercount} shows the current member count.
