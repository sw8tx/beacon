Emoji Steal Commands

Copy custom Discord emojis into your server without guessing names or pasting weird links. Paste the emoji, choose if Beacon should keep the original name, confirm it, and Beacon posts the result back into the channel.

How it works

Run one of the commands, paste a custom emoji into the command field, then set keep_name to true or false. Beacon shows the source emoji, the final server name, and a confirm step before anything gets added.

/emoji-steal

Steal one emoji. Best for quick single adds when staff only needs one reaction, badge, or server icon emoji.

Single
/emoji-steal-bulk

Steal multiple emojis in one run. Paste the emojis together, review the list, then confirm the whole batch.
