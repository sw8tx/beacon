Sticky Notes

Keep one important panel at the bottom of a channel. When a new message arrives, Beacon removes the previous panel and posts the same panel again below it.

/sticky-create

Create a V2 panel with title, message, thumbnail upload, and an optional HTTPS button.

/sticky-list

Open the private media library and select a sticky. The ID is shown in the panel footer, never as noisy body text.

/sticky-configure

Edit the selected panel in place. /sticky-remove deletes both the stored item and its live message.
