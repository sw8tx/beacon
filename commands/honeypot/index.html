Honeypot Commands

Turn one tempting channel into a quiet trap for spam and raid bots. Beacon deletes the trigger message and can ban, kick, or timeout the user.

How it works

Choose a decoy channel, configure the moderation action, and post the panel. Normal members can leave it alone; a bot that sends a message triggers Beacon immediately.
