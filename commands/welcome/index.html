Welcome panels

A clean Components V2 welcome message with a start button, server placeholders, and an image thumbnail uploaded directly through Discord.

/welcome-configure

Choose the channel, title, message, button label, and thumbnail attachment. Use {user}, {server}, and {memberCount}.

/welcome-create

Post the configured V2 panel in any text channel. The panel is used for new members from that point on.

/welcome-preview

Review the final container privately before posting. /welcome-remove disables new-member posts without deleting your copy.
