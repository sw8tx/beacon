Welcome

/welcome-create

Post a welcome panel in a channel and start with a message that matches your server.

Usage

/welcome-create channel:#welcome

What it does

Beacon posts a Components V2 welcome message with your server name, member mention and current member count. Add a thumbnail and one or two link buttons from the configure menu.

Next steps

Use /welcome-configure to change the title, message, buttons, links or thumbnail.
